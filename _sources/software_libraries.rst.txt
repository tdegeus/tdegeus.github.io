:bdg-link-info:`xtensor <https://github.com/xtensor-stack/xtensor>`
:bdg-success-line:`C++`
:bdg-secondary-line:`Maintainer`

Use NumPy-like syntax for multi-dimensional arrays in C++.
A key feature is that `teamed <https://github.com/xtensor-stack/xtensor-python>`_ with `pybind11 <https://github.com/pybind/pybind11>`_ one can directly use NumPy arrays in C++ libraries used from Python (i.e. without any copies).
